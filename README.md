  # 🐍 Анти ИИ: Змея и Мелодия (Ночью)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Бесплатный социальный офлайн-проект**, направленный на развитие когнитивных способностей (музыкальная память, реакция, пространственное мышление) и цифровую гигиену. Альтернатива алгоритмическим играм, эксплуатирующим внимание: здесь нет трекеров, рекламы и навязчивых механик удержания. Только чистый геймплей, эстетика и польза для мозга.

> 🌙 **Сеттинг:** Ночной лес, звёздное небо и загадочные светящиеся плитки. Управляйте змеёй, повторяйте музыкальные последовательности и избегайте препятствий.

---

## ✨ Особенности проекта

- 📱 **Адаптивная производительность:** Игра автоматически определяет возможности устройства (параметр `isSlow`) и динамически снижает качество теней, полигональность и количество частиц на слабых смартфонах, гарантируя стабильные 60 FPS.
- 🔊 **Процедурный звук:** Все звуковые эффекты и музыка генерируются в реальном времени через `Web Audio API` (без тяжёлых аудиофайлов).
- 🗣 **Голосовое сопровождение:** Использование `SpeechSynthesis API` для озвучивания подсказок и результатов на русском языке.
- 🎨 **Современный UI:** Стеклянный морфизм (Glassmorphism), адаптивная вёрстка (`100dvh`), корректная работа с тач-интерфейсом и предотвращение случайного зума/скролла на мобильных устройствах.
- 🛡 **Приватность и офлайн:** Не требует постоянного подключения к интернету после загрузки, не собирает данные пользователя.

## 🎮 Как играть

1. **Цель:** Проползти по светящимся плиткам в том же порядке, в котором они были показаны в начале раунда.
2. **Управление (ПК):** 
   - `←` `→` или `A` `D` — поворот змеи.
   - `↑` `↓` или `W` `S` — ускорение / замедление.
   - `Пробел` — прыжок (позволяет перепрыгнуть через дерево).
3. **Управление (Мобильные):** Используйте экранные кнопки внизу экрана (◀ ▶ для поворота, ⬆ для прыжка, ▲ ▼ для скорости).
4. **Препятствия:** Столкновение с деревом вызывает оглушение на 1.5 секунды.
5. **Победа:** Соберите 5 мелодий подряд до истечения 3-минутного таймера.

## 🛠 Технологический стек

- **Ядро:** Vanilla JavaScript (ES6+), без сборщиков и фреймворков.
- **3D-графика:** [Three.js](https://threejs.org/) (r157).
- **Стили:** CSS3 с использованием `backdrop-filter`, `clamp()` для адаптивной типографики и `@keyframes` для анимаций.
- **Развёртывание:** GitHub Pages (статический хостинг).

## 🚀 Как запустить

### Вариант 1: GitHub Pages (Рекомендуемый)
1. Создайте новый репозиторий на GitHub.
2. Загрузите файлы `index.html` (и `favicon.ico`, `foto.webp`, если есть) в корень репозитория.
3. Перейдите в **Settings** → **Pages**.
4. В разделе **Branch** выберите `main` (или `master`) и папку `/ (root)`.
5. Нажмите **Save**. Через минуту игра будет доступна по ссылке вида `https://ваш-ник.github.io/имя-репозитория/`.

### Вариант 2: Локальный запуск
Просто откройте файл `index.html` в любом современном браузере. 
*(Для корректной работы Web Audio API и загрузки текстур рекомендуется использовать локальный сервер, например, расширение "Live Server" в VS Code или команду `python -m http.server`)*.
